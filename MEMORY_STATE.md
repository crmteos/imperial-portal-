## 🗺️ 1. Огляд Системи (System Overview)
* **Назва вузла:** Медійний портал Української імперії.
* **Призначення:** Мультиагентна система управління, медіа-агрегації та координації інформаційних вузлів.
* **Стек технологій:** Node.js v22 (Express), SQLite3 (локальна БД), Supabase (хмарна БД/автентифікація), Docker.
* **Архітектура:** Модульні агенти, що взаємодіють через API `server.js` та зберігають дані в Supabase/SQLite.
